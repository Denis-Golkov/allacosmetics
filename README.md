# Alla Kern | Wise Aesthetic Cosmetology

A single-page, bilingual (Hebrew / Russian) landing page for a cosmetology clinic.
Plain HTML, CSS and JavaScript in one file, with no build step and no dependencies.

## Features

- Responsive layout for desktop and mobile
- Hebrew (RTL) and Russian (LTR) with a language switcher in the header
- Sections: hero, about, treatments, epilation feature, advantages, gallery, location (Google Maps), contact, accessibility statement, privacy policy
- Accessibility widget (font size, high contrast, link underline), skip link, keyboard focus styles
- Dark gold and plum theme based on the clinic logo
- No cookies, analytics or external fonts
